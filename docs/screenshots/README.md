## Screenshot Guidelines

- **Resolution**: 1920x1080 or higher
- **Format**: PNG for UI screenshots, GIF/MP4 for demos
- **Content**: Use realistic terminal commands and output
- **Privacy**: No sensitive information (API keys, personal data)
- **Theme**: Show both light and dark themes if applicable

## Demo GIF/Video Ideas

1. **Quick Start**: Install → Configure → First command
2. **Natural Language**: Type ">list files" → Get command → Execute
3. **Error Explanation**: Failed command → Click "Ask AI" → Get fix
4. **Skills**: Browse skills → Invoke skill → See result
5. **Search**: Search "git push" → Navigate results → Jump to command
6. **Session Save/Restore**: Save session → Close app → Reopen → Restore

## Tools

Recommended tools for screenshots/demos:
- macOS: Cmd+Shift+4 for screenshots, QuickTime for screen recording
- Linux: gnome-screenshot, kazam, peek (GIF recorder)
- Windows: Snipping Tool, ShareX
- Cross-platform: OBS Studio, Kap (macOS), ScreenToGif (Windows)

## Adding Screenshots

1. Capture screenshot/demo
2. Name descriptively (e.g., `terminal-multi-tab.png`, `ai-chat-demo.gif`)
3. Place in this directory
4. Update main README.md with links
5. Check file size (compress large images/videos)
