# pyATS CLI + Agent + Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `terminai-pyats` — a pip-installable Cisco pyATS/Genie CLI package (15-verb curated catalog + raw code executor), expose it to all AI agents as a bundled `react-code` agent, manage its device testbed entirely through a new Settings → pyATS GUI tab, and add a configurable sshpass-vs-pyATS transport toggle for tab features.

**Architecture:** Mirrors the proven `terminai-meraki` two-artifact pattern. A standalone Python package at `pyats_cli/` returns the identical typed envelope (`{ok, data/error, meta}`) used by Meraki. A sidecar bridge (`ccie_sidecar/pyats/bridge.py`) imports it in-process and feeds the existing `react-code` loop. New Tauri commands (`commands/pyats.rs`) write a GUI-managed `testbed.yaml` + `.env` (chmod 600) and run pyATS on demand. Tabs branch on a `tab_transport` setting (default sshpass — zero regression).

**Tech Stack:** Python 3.10+ (pyATS/Genie 26.4 already installed, Typer, Rich, PyYAML), Rust/Tauri, React/TypeScript/Zustand, Vitest, pytest.

**Reference patterns (read before starting):**
- `meraki_cli/src/terminai_meraki/{errors,output,client,catalog}.py` — envelope, renderers, client shape (COPY these patterns).
- `meraki_cli/src/terminai_meraki/cli/main.py` — Click CLI (pyATS uses a simpler **static** Typer app, not dynamic).
- `sidecar/src/ccie_sidecar/agents/code_exec.py` — sandbox + react-code loop (`_build_sandbox_globals`, `_build_env_overrides`, `_execute_code_with_timeout`).
- `bundled-agents/meraki/{AGENT.md,tools.json}` — bundled agent format.
- `src-tauri/src/commands/topology.rs:233` (`topology_discover_device`) + `src-tauri/src/ssh_exec/mod.rs` — the sshpass path the transport toggle branches from.

```python
"""Error envelope for terminai-pyats (mirrors terminai-meraki shape)."""

import re
from typing import Any, Dict


class PyatsError(Exception):
    """Base exception carrying a message and an actionable hint."""

    def __init__(self, message: str, hint: str = ""):
        self.message = message
        self.hint = hint
        super().__init__(message)


class ConnectError(PyatsError):
    """SSH/Unicon connection or authentication failure."""

    def __init__(self, message: str, hint: str = ""):
        super().__init__(
            message,
            hint or "Check the device IP, OS, and credentials in Settings → pyATS, "
                    "or use Test Connection. For standalone use, verify testbed.yaml + .env.",
        )


class ParseError(PyatsError):
    """Genie could not parse the command output."""

    def __init__(self, message: str, hint: str = ""):
        super().__init__(
            message,
            hint or "No Genie parser matched. The raw output is returned with "
                    "meta.parsed=false; refine the command or parse manually.",
        )


class ConfigError(PyatsError):
    """Configuration apply/rollback failure."""

    def __init__(self, message: str, hint: str = ""):
        super().__init__(
            message,
            hint or "The device rejected the configuration. Review the lines and "
                    "the device's current state.",
        )


class ValidationError(PyatsError):
    """Invalid input (unknown verb, blocked command, bad args)."""

    def __init__(self, message: str, hint: str = ""):
        super().__init__(
            message,
            hint or "Check the verb name and arguments. Run 'pyats-cli tools list'.",
        )


def to_envelope(exc: Exception) -> Dict[str, Any]:
    """Convert any exception to the standard error envelope."""
    if isinstance(exc, PyatsError):
        class_name = exc.__class__.__name__.replace("Error", "")
        code = re.sub(r"(?<!^)(?=[A-Z])", "_", class_name).lower() + "_error"
        return {"ok": False, "error": {"code": code, "message": exc.message, "hint": exc.hint}}
    return {"ok": False, "error": {"code": "unknown_error", "message": str(exc), "hint": ""}}
```

```python
"""JSON / YAML / table renderers for the envelope (reuses the Meraki shape)."""

import json
from typing import Any

import yaml
from rich.console import Console
from rich.table import Table


def render_json(envelope: dict[str, Any]) -> str:
    return json.dumps(envelope, indent=2, default=str)


def render_yaml(envelope: dict[str, Any]) -> str:
    return yaml.dump(envelope, default_flow_style=False, sort_keys=False, allow_unicode=True)


def render_table(envelope: dict[str, Any]) -> str:
    console = Console()
    if not envelope.get("ok", False):
        error = envelope.get("error", {})
        table = Table(title="[bold red]Error[/bold red]", show_header=False, border_style="red")
        table.add_column("Field", style="bold")
        table.add_column("Value")
        for field in ("code", "message", "hint"):
            if field in error:
                table.add_row(field.capitalize(), str(error[field]))
        with console.capture() as cap:
            console.print(table)
        return cap.get()

    data = envelope.get("data")
    table = Table(title="[bold]Result[/bold]", show_header=False)
    table.add_column("Key", style="bold")
    table.add_column("Value", overflow="fold")
    if isinstance(data, dict):
        for k, v in data.items():
            v_str = json.dumps(v, indent=2, default=str) if isinstance(v, (dict, list)) else str(v)
            table.add_row(k, v_str)
    else:
        table.add_row("data", json.dumps(data, indent=2, default=str))
    with console.capture() as cap:
        console.print(table)
    return cap.get()
```

```python
"""Hand-authored curated catalog of pyATS verbs.

Unlike terminai-meraki (933 introspected endpoints), pyATS exposes a small,
fixed set of device verbs. Each VerbSpec carries a JSON-schema arg description
and a base blast-radius tier. The catalog is the single source of truth for the
CLI commands, the agent tools.json dump, and blast-radius classification.
"""

from dataclasses import dataclass, asdict
from typing import Any, Dict, List, Optional


@dataclass
class VerbSpec:
    name: str               # "run-show-command"
    description: str        # human/LLM-facing one-liner
    args: Dict[str, Any]    # JSON schema: {"type":"object","properties":{...},"required":[...]}
    blast_radius: str       # "low" | "medium" | "high" | "destructive"
    destructive: bool       # base destructiveness (config screen can escalate at call time)

    def to_dict(self) -> dict:
        return asdict(self)


def _device_arg() -> Dict[str, Any]:
    return {"type": "string", "description": "Testbed device name (e.g. CORE1)."}


# --- Read verbs (Phase 1). Phase 2 appends write/config verbs to _VERBS. ---
_VERBS: List[VerbSpec] = [
    VerbSpec(
        name="list-devices",
        description="List all devices defined in the testbed.",
        args={"type": "object", "properties": {}, "required": []},
        blast_radius="low", destructive=False,
    ),
    VerbSpec(
        name="search-devices",
        description="Fuzzy-search testbed devices by name or alias.",
        args={"type": "object", "properties": {
            "query": {"type": "string", "description": "Substring to match against device names."}
        }, "required": ["query"]},
        blast_radius="low", destructive=False,
    ),
    VerbSpec(
        name="run-show-command",
        description="Run a validated show command on a device; returns Genie-parsed JSON when a "
                    "parser exists, otherwise raw text with meta.parsed=false.",
        args={"type": "object", "properties": {
            "device": _device_arg(),
            "command": {"type": "string", "description": "A 'show ...' command (no pipes/redirects)."},
        }, "required": ["device", "command"]},
        blast_radius="low", destructive=False,
    ),
    VerbSpec(
        name="run-show-command-multi",
        description="Run the same show command concurrently across multiple devices.",
        args={"type": "object", "properties": {
            "devices": {"type": "array", "description": "List of testbed device names."},
            "command": {"type": "string", "description": "A 'show ...' command."},
        }, "required": ["devices", "command"]},
        blast_radius="low", destructive=False,
    ),
    VerbSpec(
        name="learn",
        description="Run Genie learn(feature) and return structured operational state.",
        args={"type": "object", "properties": {
            "device": _device_arg(),
            "feature": {"type": "string",
                        "description": "Genie feature, e.g. bgp, ospf, interface, routing, platform."},
        }, "required": ["device", "feature"]},
        blast_radius="low", destructive=False,
    ),
    VerbSpec(
        name="ping",
        description="Ping a destination from a device.",
        args={"type": "object", "properties": {
            "device": _device_arg(),
            "destination": {"type": "string", "description": "IP or hostname to ping."},
        }, "required": ["device", "destination"]},
        blast_radius="low", destructive=False,
    ),
]

_INDEX: Optional[Dict[str, VerbSpec]] = None


def get_catalog() -> List[VerbSpec]:
    """Return the full verb catalog (stable order)."""
    return list(_VERBS)


def find_verb(name: str) -> Optional[VerbSpec]:
    """O(1) lookup of a verb by name, or None."""
    global _INDEX
    if _INDEX is None:
        _INDEX = {v.name: v for v in _VERBS}
    return _INDEX.get(name)
```

```python
"""Load a pyATS testbed.yaml with %ENV{VAR} substitution from a sibling .env.

Kept independent of pyATS itself so it is unit-testable without devices. The
actual Genie Testbed object is built lazily in client.py via genie.testbed.load,
which understands the same %ENV{} convention; this module is used for the
TerminAI bridge that needs the resolved dict (e.g. to enumerate devices).
"""

import os
import re
from pathlib import Path
from typing import Any, Dict

import yaml

_ENV_RE = re.compile(r"%ENV\{([A-Za-z0-9_]+)\}")


def _load_env_file(env_path: Path) -> None:
    """Load KEY=value lines from a .env into os.environ (does not overwrite existing)."""
    if not env_path.exists():
        return
    for line in env_path.read_text().splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        key, _, val = line.partition("=")
        key = key.strip()
        val = val.strip().strip('"').strip("'")
        if key:
            os.environ.setdefault(key, val)


def substitute_env(obj: Any) -> Any:
    """Recursively replace %ENV{VAR} tokens in strings using os.environ ('' if unset)."""
    if isinstance(obj, dict):
        return {k: substitute_env(v) for k, v in obj.items()}
    if isinstance(obj, list):
        return [substitute_env(v) for v in obj]
    if isinstance(obj, str):
        return _ENV_RE.sub(lambda m: os.environ.get(m.group(1), ""), obj)
    return obj


def load_testbed_dict(testbed_path: str) -> Dict[str, Any]:
    """Read testbed.yaml, load the sibling .env, return the env-substituted dict."""
    path = Path(testbed_path).expanduser()
    _load_env_file(path.parent / ".env")
    raw = yaml.safe_load(path.read_text()) or {}
    return substitute_env(raw)
```

```python
"""PyatsClient — connects to testbed devices and dispatches catalog verbs,
returning the standard {ok, data/error, meta} envelope (same shape as Meraki)."""

import time
from typing import Any, Dict, Optional, Set

from .catalog import find_verb
from .errors import ConnectError, ValidationError, to_envelope
from .verbs import show, learn, ops, inventory


class PyatsClient:
    """Wraps a Genie testbed. One connection per device, cached for the process."""

    def __init__(self, testbed_path: str):
        from genie.testbed import load  # imported here so unit tests can bypass via __new__
        self._testbed = load(testbed_path)
        self._connected: Set[str] = set()

    @classmethod
    def from_testbed(cls, testbed_path: str) -> "PyatsClient":
        return cls(testbed_path)

    # ----- connection management -----
    def _device(self, name: str):
        dev = self._testbed.devices.get(name)
        if dev is None:
            raise ConnectError(f"device '{name}' is not in the testbed")
        if name not in self._connected:
            try:
                dev.connect(log_stdout=False, learn_hostname=True)
            except Exception as exc:
                raise ConnectError(f"failed to connect to '{name}': {exc}") from exc
            self._connected.add(name)
        return dev

    def disconnect_all(self) -> None:
        for name in list(self._connected):
            try:
                self._testbed.devices[name].disconnect()
            except Exception:
                pass
            self._connected.discard(name)

    # ----- dispatch -----
    def call(self, verb: str, **kwargs) -> Dict[str, Any]:
        start = time.time()
        spec = find_verb(verb)
        if spec is None:
            return self._error_env(ValidationError(f"unknown verb '{verb}'"), verb, start, kwargs)

        # Validate required args present.
        missing = [r for r in spec.args.get("required", []) if kwargs.get(r) in (None, "")]
        if missing:
            return self._error_env(
                ValidationError(f"missing required argument(s) for '{verb}': {', '.join(missing)}"),
                verb, start, kwargs,
            )

        try:
            data = self._dispatch(verb, kwargs)
        except Exception as exc:
            return self._error_env(exc, verb, start, kwargs)

        from .blast_radius import classify  # Phase 2 module; falls back to spec tier if absent
        try:
            tier, destructive = classify(verb, kwargs)
        except Exception:
            tier, destructive = spec.blast_radius, spec.destructive

        return {
            "ok": True,
            "data": data,
            "meta": {
                "verb": verb,
                "device": kwargs.get("device"),
                "blast_radius": tier,
                "destructive": destructive,
                "duration_ms": int((time.time() - start) * 1000),
            },
        }

    def _dispatch(self, verb: str, kw: Dict[str, Any]) -> Any:
        if verb == "list-devices":
            return inventory.list_devices(self._testbed)
        if verb == "search-devices":
            return inventory.search_devices(self._testbed, query=kw["query"])
        if verb == "run-show-command":
            return show.run_show_command(self._device(kw["device"]), command=kw["command"])
        if verb == "run-show-command-multi":
            results = {}
            for name in kw["devices"]:
                results[name] = show.run_show_command(self._device(name), command=kw["command"])
            return {"results": results}
        if verb == "learn":
            return learn.learn_feature(self._device(kw["device"]), feature=kw["feature"])
        if verb == "ping":
            return ops.ping(self._device(kw["device"]), destination=kw["destination"])
        # Phase 2 verbs are dispatched by an extended _dispatch (Task 11).
        return self._dispatch_phase2(verb, kw)

    def _dispatch_phase2(self, verb: str, kw: Dict[str, Any]) -> Any:
        raise ValidationError(f"verb '{verb}' is not implemented")

    def _error_env(self, exc: Exception, verb: str, start: float,
                   kw: Dict[str, Any]) -> Dict[str, Any]:
        env = to_envelope(exc)
        env["meta"] = {"verb": verb, "device": kw.get("device"),
                       "duration_ms": int((time.time() - start) * 1000)}
        return env
```

```python
"""Input-safety screening for pyATS verbs.

- validate_show_command: only allow read commands; block shell metacharacters.
- contains_destructive_keyword: flag config payloads that should escalate to the
  'destructive' blast-radius tier.
"""

import re
from .errors import ValidationError

_SHELL_METACHARS = ("|", ">", "<", ";", "&", "`", "$(")
_READ_PREFIXES = ("show", "ping", "traceroute", "dir", "more")

_DESTRUCTIVE = (
    "reload", "write erase", "erase ", "format ", "delete ",
    "boot system", "factory-reset", "clear ", "no boot",
)


def validate_show_command(command: str) -> None:
    """Raise ValidationError unless `command` is a safe read command."""
    cmd = command.strip()
    if not cmd:
        raise ValidationError("empty command")
    for ch in _SHELL_METACHARS:
        if ch in cmd:
            raise ValidationError(f"command contains disallowed character '{ch}'",
                                  hint="Pipes, redirects, and command chaining are not allowed.")
    first = cmd.split()[0].lower()
    if first not in _READ_PREFIXES:
        raise ValidationError(f"'{first}' is not an allowed read command",
                              hint=f"run-show-command only accepts: {', '.join(_READ_PREFIXES)}.")


def contains_destructive_keyword(config: str) -> bool:
    """True if any destructive keyword appears in the config payload (case-insensitive)."""
    low = config.lower()
    return any(re.search(re.escape(kw), low) for kw in _DESTRUCTIVE)
```

```python
"""Blast-radius classifier. Base tier comes from the catalog; config-bearing
verbs (and run-pyats-code) escalate to 'destructive' when the destructive-keyword
screen fires, and to 'low' for read-only code."""

from typing import Any, Dict, Tuple

from .catalog import find_verb
from .safety import contains_destructive_keyword

_TIER_ORDER = {"low": 0, "medium": 1, "high": 2, "destructive": 3}

# config-bearing verbs whose payload should be screened for destructive keywords
_CONFIG_VERBS = {"configure", "configure-multi", "configure-with-diff", "run-pyats-code"}


def classify(verb: str, args: Dict[str, Any]) -> Tuple[str, bool]:
    """Return (tier, destructive) for a verb call."""
    spec = find_verb(verb)
    base = spec.blast_radius if spec else "medium"
    base_destructive = spec.destructive if spec else False

    if verb in _CONFIG_VERBS:
        payload = args.get("config") or args.get("code") or ""
        if contains_destructive_keyword(payload):
            return "destructive", True
        # run-pyats-code with no config keyword and no .configure( call is a read.
        if verb == "run-pyats-code" and ".configure(" not in payload and "configure" not in payload:
            return "low", False

    return base, base_destructive
```

```python
"""Configuration verbs with snapshot/diff/rollback support.

Snapshots are written under <snapshot_dir>/<device>/running-config.txt so
rollback-config can restore the last known-good. The client passes snapshot_dir."""

import difflib
import os
from typing import Any, Dict


def _snapshot_path(snapshot_dir: str, device_name: str) -> str:
    d = os.path.join(os.path.expanduser(snapshot_dir), device_name)
    os.makedirs(d, exist_ok=True)
    return os.path.join(d, "running-config.txt")


def configure(device, config: str) -> Dict[str, Any]:
    """Apply config lines to a device."""
    device.configure(config)
    return {"applied": True, "lines": config.splitlines()}


def configure_with_diff(device, config: str, snapshot_dir: str) -> Dict[str, Any]:
    """Snapshot running-config, apply config, return unified diff; save snapshot for rollback."""
    before = device.execute("show running-config")
    path = _snapshot_path(snapshot_dir, device.name)
    with open(path, "w") as f:
        f.write(before)
    device.configure(config)
    after = device.execute("show running-config")
    diff = "\n".join(difflib.unified_diff(
        before.splitlines(), after.splitlines(),
        fromfile="before", tofile="after", lineterm=""))
    return {"applied": True, "diff": diff}


def rollback_config(device, snapshot_dir: str) -> Dict[str, Any]:
    """Restore the last snapshot saved by configure_with_diff."""
    path = _snapshot_path(snapshot_dir, device.name)
    if not os.path.exists(path):
        return {"restored": False, "reason": "no snapshot found"}
    with open(path) as f:
        saved = f.read()
    device.configure(saved)
    return {"restored": True}
```

```python
- Resolves the GUI-managed testbed path.
- Builds a PyatsClient (or None if the testbed is absent).
- Injects the client into the react-code sandbox under the name `pyats`, the
  same way code_exec injects the Meraki SDK.

import os
from typing import Any, Dict, Optional


def default_testbed_path() -> str:
    return os.path.expanduser(os.path.join("~", ".ccie-terminal", "pyats", "testbed.yaml"))


def build_pyats_client(path: Optional[str] = None):
    """Return a PyatsClient bound to the testbed, or None if the file is missing."""
    testbed_path = path or default_testbed_path()
    if not os.path.exists(testbed_path):
        return None
    from terminai_pyats import PyatsClient
    client = PyatsClient.from_testbed(testbed_path)
    # Point config snapshots at the GUI-managed dir.
    client._snapshot_dir = os.path.join(os.path.dirname(testbed_path), "snapshots")
    return client

    """Inject a `pyats` PyatsClient into a code-exec sandbox namespace if available."""
    client = build_pyats_client(testbed_path)
    if client is not None:
        globals_dict["pyats"] = client
```

```rust
    for d in devices {
        let up = d.name.to_uppercase();
        s.push_str(&format!("  {}:\n", d.name));
        s.push_str(&format!("    os: {}\n", d.os));

        }
        s.push_str("    credentials:\n      default:\n");

        s.push_str(&format!("        password: \"%ENV{{{}_PASSWORD}}\"\n", up));

        s.push_str(&format!("        ip: \"%ENV{{{}_IP}}\"\n", up));
```

```rust
        Err(e) => Ok(PyatsConnTest { ok: false, message: e.to_string() }),
    }

/// Pull devices from the topology inventory into the pyATS device shape.
```

```typescript
  addDevice: (d) => set((s) => ({ devices: [...s.devices, d] })),
  updateDevice: (index, d) =>
    set((s) => ({ devices: s.devices.map((x, i) => (i === index ? d : x)) })),

}));
```

```rust
/// Convert a pyATS get-neighbors envelope into the topology graph via the
/// existing ingest pipeline. Each protocol's parsed output is re-serialized to
/// text and run through the existing parser_bridge so both transports converge
/// on the same normalized neighbor shape.
pub fn ingest_pyats_neighbors(
    state: &AppState,
    device_name: &str,
    _vendor: &str,
    _platform: &str,
    envelope: serde_json::Value,
) -> Result<crate::topology::IngestSummary, String> {
    if !envelope.get("ok").and_then(|v| v.as_bool()).unwrap_or(false) {
        let hint = envelope.pointer("/error/hint").and_then(|v| v.as_str()).unwrap_or("");
        return Err(format!("pyats get-neighbors failed: {hint}"));
    }
    // The parsed neighbor data already matches Genie's structure; persist it
    // through the same cache/ingest path the sshpass route uses. The sidecar
    // bridge returns Genie-parsed dicts under data.neighbors.{cdp,lldp}.
    let neighbors = envelope.pointer("/data/neighbors").cloned().unwrap_or(serde_json::json!({}));
    let conn = state.db.lock();
    crate::topology::ingest::ingest_pyats_parsed(&conn, device_name, &neighbors)
        .map_err(|e| e.to_string())
}
```

```typescript
import { invoke } from "@tauri-apps/api/core";

/** Run a single pyATS verb and return its envelope. */
export async function runPyats(
  verb: string,
  device?: string,
  args: Record<string, unknown> = {},
): Promise<unknown> {
  return invoke("pyats_run", { request: { verb, device: device ?? null, args } });
}

export interface DiscoverParams {
  connectionId: string;
  vendor: string;
  platform: string;
  password?: string;
}

/** Discover topology using the user's selected transport (default sshpass). */
export async function discoverWithTransport(p: DiscoverParams): Promise<unknown> {
  const transport = usePyatsStore.getState().transport;
  return invoke("topology_discover_device", {
    connectionId: p.connectionId,
    vendor: p.vendor,
    platform: p.platform,
    password: p.password ?? null,
    transport,
  });
}
```
