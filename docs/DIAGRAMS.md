# Diagrams (draw.io)

CCIE Terminal can turn agent output into draw.io diagrams — network topologies,
flowcharts, org charts — with **zero setup**. There is nothing to install: the
diagramming capability is built into the bundled Python sidecar and a bundled
offline draw.io viewer ships with the app.

This is a native reimplementation of the [`@drawio/mcp`](https://github.com/jgraph/drawio-mcp)
tool server's URL scheme (no Node.js, no MCP server process, no browser
extension).

## Using it

Ask any **code-capable** agent to draw something:

> "Draw a topology diagram of the devices in my testbed."
>
> "Diagram the uplinks between my Meraki networks."

The agent writes Python that calls the pre-loaded `drawio` helper. When it does,
the **Diagram viewer** opens automatically and renders the result.

Open the viewer manually any time:

- Menu: **Operate → Diagrams → Open Diagram Viewer**
- Shortcut: **⌘⇧I** (Ctrl+Shift+I on Windows/Linux)

## Inline vs. open-in-browser

| Format | Inline (offline) preview | Open in draw.io editor |
| ------ | ------------------------ | ---------------------- |
| draw.io / mxGraph **XML** | ✅ rendered in-app, offline | ✅ |
| **Mermaid** | ❌ (opens in editor) | ✅ |
| **CSV** | ❌ (opens in editor) | ✅ |

Native draw.io XML is rendered **inline and fully offline** by the bundled
viewer — no network needed. Mermaid and CSV are draw.io *editor import* formats
(the offline viewer can't render them), so they show an "Open in draw.io"
button that launches the editor in your system browser. The **Open in draw.io**
button is available for every diagram and opens the full editor for editing and
export (PNG/SVG/PDF).

## The `drawio` helper (for agent authors)

Every agent with `execution-mode: code` or `react-code` gets a `drawio` object
pre-loaded in its sandbox:

```python
# Native draw.io / mxGraph XML — renders inline in the app.
drawio.diagram(xml="<mxGraphModel>...</mxGraphModel>", title="Campus topology")

# Mermaid source — opens in the draw.io editor.
drawio.from_mermaid("graph TD; Core-->Dist; Dist-->Access", title="L3 design")

# draw.io CSV import — opens in the draw.io editor.
drawio.from_csv("name,parent\nCore,\nDist,Core", title="Hierarchy")
```

Each call:

1. Renders the diagram for the user (inline for XML, button for the rest).
2. Returns `{"title", "format", "xml", "source", "url"}` so the agent can also
   reference the URL.

Do **not** `print()` the raw XML — call `drawio.diagram(...)` instead.

## Limitations

- **Stream-only agents have no diagramming.** Agents with the default
  `execution-mode: stream` (plain chat) do not run a code sandbox, so the
  `drawio` helper is unavailable to them. Use a `code` or `react-code` agent
  (the bundled **meraki** and **pyats** agents are both `react-code`).
- **Inline preview is XML-only.** Mermaid/CSV require the online editor.

## Security notes

The diagram source is generated by the LLM and treated as untrusted:

- Inline rendering happens inside a **sandboxed, same-origin iframe** with a
  strict per-document CSP (`connect-src 'none'`, `img-src 'self' data:`), so a
  malicious diagram cannot phone home or exfiltrate embedded infrastructure
  data. Telemetry and remote-font requests from the bundled viewer fail closed.
- **Open in draw.io** only opens `https://` URLs on a small allowlist of
  official draw.io hosts (`app.diagrams.net`, `viewer.diagrams.net`,
  `embed.diagrams.net`, `draw.io`, `www.draw.io`). Any other URL is refused.
- The bundled viewer requires `'unsafe-eval'` in the app CSP (mxGraph uses
  `eval`); inline scripts remain blocked (`script-src` has no `'unsafe-inline'`).
